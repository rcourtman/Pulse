## Release Metadata

- Version: `v6.7.0-beta.1`
- Previous stable: `v6.6.0`
- Rollback target: `v6.6.0`
- Rollback command: `sudo /bin/update --version v6.6.0`
- Promotion path: exact-SHA single-build release candidate from `main`
- Windows signing decision: prereleases publish checksum- and detached-signature-verified Windows agents without Authenticode while SignPath remains unavailable. Windows Unified Agent binaries may display an Unknown Publisher warning
- Mobile decision: `no-mobile-impact`. No governed mobile route, payload, Relay, pairing, approval, push or onboarding contract changed from `v6.6.0`, so no companion mobile build or store rollout is required
